### Questão 05 - Associe descrição a nome de processo que melhor designa o conceito descrito.

Processo de teste onde software é avaliado por pequeno grupo de usuários e pode expor software a usos não previstos pelos desenvolvedores. $\rightarrow$ **Teste alfa**,  
Processo de teste que verifica se software satisfaz requisitos considerados necessários para o mesmo ser aprovado pelo cliente. $\rightarrow$ **Teste de aceitação**,  
Processo de teste que verifica software como um todo e que verifica interfaces do software com elementos externos ao software. $\rightarrow$ **Teste de sistema**,  
Processo de teste que verifica interações entre parte dos elementos que integram o software e interfaces entre esses elementos. $\rightarrow$ **Teste de integração**,  
Processo de teste frequentemente estrutural onde elemento em teste é verificado separado de outros elementos do software. $\rightarrow$ **Teste de unidade**,  
Processo de teste que verifica se modificação não resulta em falha quando de caso de teste que não resultava em falha antes da modificação. $\rightarrow$ **Teste de regressão**.

### Questão 11 - Selecione todas as opções verdadeiras acerca de teste de software.

### Questão 20 - Selecione todas as opções verdadeiras acerca de teste de software.

**a. Teste de segurança (security testing) verifica se software está protegido contra ataques externos; pode verificar confidencialidade, disponibilidade, comportamento do software quando de mal uso do mesmo.**  
**b. Teste de recuperação (recovery testing) é realizado com o propósito de verificar capacidade de reinício (restart) do software após colapso do sistema (system crash) ou de outro desastre.**  
**c. Teste de desempenho (performance testing) verifica se software atende a requisitos de desempenho (performance); verifica características de desempenho, tal como capacidade ou tempo de resposta.**  
**d. Teste de estresse (stress testing) exercita software com carga elevada, pode ser realizado para determinar comportamento limite ou verificar mecanismo de defesa.**
