### Questão 06 - Selecione todas as opções verdadeiras acerca de interface em projeto (design) de software.
**a. Em um sistema de software, pode existir elemento que realize mais de uma interface, assim como pode existir elemento que dependa de mais de uma interface. Um elemento que realiza uma interface, provê os serviços relacionados na interface. Um elemento que depende de uma interface, solicita serviços relacionados na interface. Portanto, esse elemento é cliente de serviços relacionados na interface.**  
b. Em processo de projeto (design) de software, é relevante identificar e especificar interfaces entre elementos do sistema de software. Podem ser identificadas e especificadas interfaces entre sistemas de software, entre subsistemas de software, entre módulos de programa e entre classes. Cada uma das interfaces não pode ser realizada por mais de um elemento integrante de um mesmo sistema de software.  
c. Em um sistema de software, cada elemento integrante do sistema pode realizar interface ou depender de interface. Não é possível que um mesmo elemento realize determinada interface e dependa de outra interface. Cada elemento pode ser servidor ou cliente. Portanto, um elemento integrante de sistema de software não pode ser servidor em determinado instante, e ser cliente em um outro instante.  
**d. Quando da especificação de interface realizada por classe, métodos da interface são métodos públicos da classe. Quando da especificação de interface a ser realizada por classe, procura-se não incluir detalhes acerca das representações dos dados armazenados por instâncias da classe. Pode-se, entretanto, incluir métodos para acessar esses dados. Procura-se ocultar detalhes das representações desses dados.**

### Questão 20 - Associe cada definição de conceito acerca de projeto (design) ao termo que melhor designa o conceito definido.
Processo de decomposição de programa em partes com interfaces definidas. $\rightarrow$ **Modularização.**    
Visão de elemento que enfoca informação relevante a determinado propósito e ignora informação restante. $\rightarrow$ **Abstração.**     
Medida de grau de relacionamento funcional existente entre serviços disponibilizados por elemento de sistema de software. $\rightarrow$ **Coesão.**  
Medida de interdependência entre elementos em sistema de software. $\rightarrow$ **Acoplamento.**  
Processo onde detalhes internos de elemento são agrupados e escondidos, e esses detalhes são tornados inacessíveis a elementos externos. $\rightarrow$ **Encapsulamento.**
